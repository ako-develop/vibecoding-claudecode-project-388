# Правила трекера

## Постановка

Ниша: SO-DIMM DDR5-5600 комплектом 2×16 ГБ и Samsung 980 PRO на 1–2 ТБ.
Цель: заметить снижение цены для покупки памяти и SSD. Локация — Россия, валюта — RUB.
Регион сравнения по умолчанию — Москва, если карточка явно не относится к другому региону; регион фиксируется для каждой ссылки.
Стартовый список — `products.json`, журнал проверки — `docs/url-check.md`.
Сравнивать каждую карточку с её собственной историей. Не смешивать цены разных магазинов, регионов и способов оплаты.
Совместимость накопителя с устройством пользователя пока не подтверждена.

## Контракт цены

Определение для выбранных карточек; инструкция `extract-price` находится в `.agents/skills/extract-price/SKILL.md`.

- `regular_price`: полная обычная цена товара, включая явно показанную зачёркнутую цену до скидки. Если показана только одна обычная цена, она записывается сюда.
- `sale_price`: полная публичная цена со скидкой. Если скидка не указана — `null`. Не подменять её ежемесячным платежом или персональной ценой по карте.
- `has_credit`: `true`, если для товара явно предлагается кредит или рассрочка; иначе `false` (подтверждённого предложения не найдено). По контракту это всегда boolean. При ошибке чтения обе цены — `null`, `has_credit` — `false`; это не доказательство отсутствия кредита. Причину ошибки вызывающий процесс фиксирует отдельно.

Цены записываются числами в одной выбранной валюте. Недоступная цена — `null`, никогда не ноль. Ошибка загрузки не означает снижение цены.

Регион и валюта должны оставаться одинаковыми между прогонами. Доставку и персональные скидки не смешивать с публичной ценой товара.

Для Онеком отслеживать полную цену при наличном расчёте; безналичная цена — другой способ оплаты, не скидка. Для Борн — опубликованную безналичную цену с НДС. Для Softline — публичную цену для юридических лиц и ИП, только как рыночный ориентир: это не предложение для личной покупки. Клубную цену KNS не учитывать.

Если указана только «последняя цена» отсутствующего товара, текущие `regular_price` и `sale_price` равны `null`. Отсутствие товара, предзаказ, запрет доступа и ошибка загрузки — разные состояния, их нужно отмечать в результате обхода. Не превращать их в уведомления о скидке.

## Значимость изменений

Порог и правила уведомлений будут определены на шаге сравнения прогонов.
