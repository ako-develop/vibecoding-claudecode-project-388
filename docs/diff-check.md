Через GitHub MCP получен список корня приватного tracker-data; среди файлов YYYY-MM-DD.json выбран последний — 2026-11-05.json. Исходный снимок имел collected_at=22:09:50+03:00 и blob SHA ce66cb9d887ffbf1e7b59bf9a2c421b25aab227d.

1. Повторно прочитаны все пять карточек и применён extract-price. Снимок 22:16:46+03:00 сравнён с исходным helper-скриптом diff.py до записи: first_run=false, raw_diff=[], significant_changes=[], diagnostics=[]. Сохранён через MCP: [коммит 45e3f8b](https://github.com/ako-develop/tracker-data/commit/45e3f8b7251749fe10af5c2f3926071067a20964).
2. Снова получен список файлов и прочитан сохранённый снимок 22:16:46+03:00. Все пять URL открыты повторно. Снимок 22:18:24+03:00 сравнён именно с первым из этих двух прогонов: first_run=false, raw_diff=[], significant_changes=[], diagnostics=[]. Сохранён через MCP: [коммит bbf2c687](https://github.com/ako-develop/tracker-data/commit/bbf2c68762f42dbe5f0a3e9e34d641267a8c188f).

После каждой записи JSON прочитан обратно и сопоставлен с отправленным объектом; совпадает. Обе записи проверены чтением коммитов: меняется только 2026-11-05.json. В обоих случаях корректный пользовательский результат — «Значимых изменений нет», а не список всех цен.

Веб-инструмент в обоих прогонах вернул кеш. Одинаковые наблюдения не подтверждают отсутствие изменений в магазинах в реальном времени. Статус read_cached и возраст кеша сохранены в снимках. Рабочие цены вручную не менялись.

## Контрольные примеры

tests/test_diff.py использует только вымышленные example.com URL и цены; тестовые значения не записываются в tracker-data.

Восемь тестов прошли: первый запуск/отсутствие изменений, границы ±1%, фильтрация списка товаров, появление/исчезновение скидки и кредита, null/ошибки чтения, добавление/удаление URL и смена контекста, повреждённая история/смена валюты, маркировка кеша.

Проверка фильтрации: у первого товара 10 000 → 9 999,99, у второго 10 000 → 9 000. Полный diff содержит 2 строки, значимый — только вторую (−10%). Ровно −1% и +1% проходят; −0,9999% не проходит. Появление скидки даже на копейку даёт событие sale_started по выбранным правилам.

Расчёт использует стандартную библиотеку Python и Decimal; порог читается из машиночитаемого блока KNOWLEDGE.md. GitHub по-прежнему читает и обновляет агент через MCP, helper только сравнивает JSON во временных файлах. Автоматический запуск по расписанию и отправка Telegram на этом шаге не добавлялись.
